# Website Images & Assets Folder

Store all your website images here to display them on your personal site!

## 1. Profile Display Picture (Home Page Banner)
* Preferred file name: **`Shuvajit_DP.png`** (also supports **`Shuvajit_DP.jpg`** or **`profile.jpg`** as secondary options)
* Location: Place your profile picture directly in this folder:
  `assets/images/Shuvajit_DP.png`
* Note: The website banner is configured to check for `Shuvajit_DP.png` first, then `Shuvajit_DP.jpg`, and then `profile.jpg`. If any of these are present, it will automatically override the default placeholder and display your face!

## 2. Photography Gallery Portfolio
* Location: Store your custom photography pictures inside the `gallery/` sub-folder:
  `assets/images/gallery/`
* Recommended files names:
  * `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, etc.
* Customizing the list: Open `data/photos.json` to edit details (Title, Description, Location, and Date) for each photograph!
